Dear Actor

소개

꿈속에서 별을 찾아 떠나는 여정은 잠에서 깨어난 뒤 현실의 별을 만나러 가는 장면으로 이어집니다.

이 작품은 꿈과 현실을 오가는 이야기를 바탕으로, 관객이 조명과 소리를 직접 조정하며 자신만의 장면을 만들어가는 인터랙티브 경험입니다.

같은 장면도 빛과 소리가 달라지면 새로운 분위기와 감정을 품게 됩니다. 관객은 이야기를 바라보는 동시에, 장면의 분위기를 결정하는 연출자가 됩니다. 꿈속의 별을 찾아가는 순간부터 현실의 별을 마주하는 순간까지, 각자의 감각과 상상으로 이야기를 이어갈 수 있습니다.

빛과 소리로 장면에 나만의 해석을 더하며, 자신만의 작은 연극을 만들어보세요.

주요 업무

스토리 기획

- 왼쪽에서 오른쪽으로 이동하며 이야기가 전개되는 공간적 흐름 설계

- 중앙의 침대를 꿈꾸는 공간으로 설정하고, 꿈속에서 별을 발견한 뒤 잠에서 깨어 오른쪽의 현실 공간에서 다시 별을 찾아가는 서사 기획

Remote Control 기반 인터랙션 개발

- 동일한 네트워크에 연결된 스마트폰·태블릿의 웹 브라우저에서 Unreal Engine 실행 PC의 IP 주소로 접속하는 원격 제어 기능 구현

- 조명의 켜기·끄기, 밝기, 각도 조절 및 무대 오브젝트를 내리는 동작을 연결하여 사용자의 속도에 따라 이야기를 진행하는 인터랙션 구현

- 여러 기기에서 조작한 제어 값을 동기화하여 다른 사용자의 조작 결과도 실시간으로 반영되는 공동 제어 환경 구성

레벨 디자인

이야기의 흐름에 맞춰 오브젝트를 배치하고, 꿈과 현실의 장면을 표현하는 레벨 디자인

문제 해결과 배운 점

여러 사용자가 하나의 공간을 함께 제어하는 인터랙션을 구현하며, 기기 간 데이터 동기화의 중요성을 배웠습니다. 각 사용자의 조작이 다른 기기와 콘텐츠에 실시간으로 반영되어야 모두가 같은 상태를 공유할 수 있다는 점을 이해하고, 다중 사용자 환경에서 일관된 경험을 제공하는 방법을 고민했습니다.
