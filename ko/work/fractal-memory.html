소개

Arte Kids Park의 Live Sketchbook은 관람객이 색칠한 그림을 미디어월 속 캐릭터로 연결하는 참여형 콘텐츠입니다. 종이 위의 그림이 가상 공간에 등장하는 경험을 위해 이미지 처리, 캐릭터 움직임, 공간 연출 시스템을 개발했습니다.

주요 업무

웹캠으로 촬영한 스케치 이미지의 저장·전송 및 OpenCV 기반 텍스처 변환

디자인팀의 3D 에셋을 활용한 레벨 구성과 셰이더 개발

캐릭터 이동 경로, 개체 수 테스트 및 낮과 밤의 전환 시스템 개발

다중 프로젝터 출력·동기화와 블렌딩·매핑 테스트

Process

01 공간의 분위기와 움직임

디자인팀에서 제작한 3D 에셋을 바탕으로 미디어월의 레벨을 구성했습니다. Timeline으로 낮과 밤의 변화를 연결하고, 수련잎의 흔들림과 거리 안개를 셰이더로 구현했습니다. 볼풀 공간에는 물속에 있는 듯한 느낌을 주는 프로젝션 셰이더를 개발했습니다.

02 그림을 캐릭터로 연결하기

웹캠으로 촬영한 스케치를 HTTP 기반 웹 서버에 저장하고, FTP를 통해 실행 PC로 전달하도록 구성했습니다. QR 마커가 포함된 스케치 이미지는 OpenCV로 처리해 캐릭터의 UV 텍스처로 변환했습니다.

03 출력 환경에 맞춘 조정

초기에는 8K 이상의 출력을 고려해 Unreal Engine과 nDisplay를 테스트했습니다. 이후 출력 해상도 조건이 바뀌면서 Unity 기반 구성으로 전환했습니다. Immersive Display PRO를 활용한 블렌딩·매핑도 테스트하며 현장 출력 조건에 맞춰 구성을 조정했습니다.
