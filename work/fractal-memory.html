Introduction

Live Sketchbook at Arte Kids Park brings visitors’ drawings into a shared digital environment. A character coloured on paper appears on the media wall. My work connected image processing, character movement and spatial visuals to support this experience.

Responsibilities

Developed webcam image capture, storage and transfer, with OpenCV processing to generate character textures.

Built levels and shaders using 3D assets provided by the design team.

Developed character paths, population tests and day-to-night transitions.

Tested multi-projector output, synchronisation, blending and mapping.

Process

01 Building the environment

Using 3D assets from the design team, I assembled the media-wall environment and used Timeline to connect day and night. Shaders added movement to the lily pads and distance fog, while a separate projection shader created an underwater feeling in the ball-pit area.

02 From drawing to character

Sketches captured by a webcam were stored on a web server over HTTP and transferred to the playback PC via FTP. OpenCV processed the sketches containing QR markers and converted them into textures for the characters’ UV layouts.

03 Adapting to the output setup

The initial output plan exceeded 8K, so I tested Unreal Engine with nDisplay. When the resolution requirements changed, the project moved to a Unity-based setup. I also tested blending and mapping with Immersive Display PRO to adapt the output to the installation.
